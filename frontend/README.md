# Parkinson's Prediction – Frontend

A React-based web application for an AI-powered Parkinson's disease prediction system. The frontend provides an interactive interface for entering clinical and voice-related parameters, communicating with the prediction API, and displaying the prediction results in a clear and user-friendly dashboard.

## Features

* Clean and responsive React user interface
* Parkinson's prediction input form
* Integration with the FastAPI backend
* Prediction result dashboard
* Medical information and symptom guidance
* Hospital and healthcare resource links
* Responsive design for desktop and mobile devices
* Client-side form validation
* Interactive navigation using React Router

## Tech Stack

* **Frontend:** React.js
* **Styling:** CSS
* **Routing:** React Router
* **State Management:** Redux
* **API Communication:** REST API
* **Backend:** FastAPI
* **Development Server:** Create React App

## Getting Started

### Prerequisites

Make sure the following are installed:

* Node.js
* npm
* Git

### Installation

Clone the repository:

```bash
git clone <your-frontend-repository-url>
```

Navigate to the project directory:

```bash
cd <project-folder>
```

Install dependencies:

```bash
npm install
```

### Run the Application

Start the development server:

```bash
npm start
```

The application will be available at:

```text
http://localhost:3000
```

## Backend Integration

The frontend communicates with a FastAPI backend that provides the Parkinson's prediction API.

During local development, the backend can be run at:

```text
http://127.0.0.1:8000
```

FastAPI's interactive API documentation is available at:

```text
http://127.0.0.1:8000/docs
```

Make sure the backend is running before submitting a prediction from the frontend.


## Backend Requirement

This repository contains the **frontend** of the Parkinson's Prediction system.

The prediction functionality requires the corresponding **FastAPI backend and trained machine learning model** to be running and accessible through the configured API endpoint.
